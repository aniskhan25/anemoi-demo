# GitHub Pages Source

This branch contains the Chirpy-based GitHub Pages site for the
`aniskhan25/anemoi-demo` repository.

## Local Preview

Use Ruby 3.1.x through 3.4.x for local preview.

```bash
bundle install
bundle exec jekyll serve
```

The published project site URL is:

```text
https://aniskhan25.github.io/anemoi-demo/
```
