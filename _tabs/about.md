This site publishes concise setup notes for the
[`aniskhan25/anemoi-demo`](https://github.com/aniskhan25/anemoi-demo)
repository.

The focus is practical usage on **LUMI-G**:

- minimal Anemoi training setup
- validation and smoke-test flows
- small multi-GPU and multi-node launch patterns

The runnable code stays on the repository's `main` branch. This site branch is only for documentation and GitHub Pages publishing.
